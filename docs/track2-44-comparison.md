# Track 2: 4.4 m/s baseline and residual RL comparison

The official `evaluate.launch.py` referee scored these runs against the
connected Windows AutoDRIVE compete simulator on 29 September 2026. Each run
used the same map-derived racing line, 4.4 m/s straight-line target, 1.5 m/s²
lateral acceleration limit, 2.0 m/s² planned braking limit, 5.5 m LiDAR
horizon, two unscored laps, and ten timed laps. The only comparison switch was
`baseline_only` in the driver parameter YAML.

| Driver | Run | Status | Collisions | Best penalized lap | Penalized 10-lap total |
| --- | --- | --- | ---: | ---: | ---: |
| Baseline | `baseline44_a` | COMPLETE | 0 | 19.940 s | 200.180 s |
| RL | `rl44_a` | COMPLETE | 0 | 19.766 s | 198.073 s |
| Baseline | `baseline44_b` | COMPLETE | 0 | 19.949 s | 199.922 s |
| RL | `rl44_b` | COMPLETE | 0 | 19.716 s | 197.779 s |
| Promoted RL, final code | `selected44_e` | COMPLETE | 0 | 19.728 s | 197.962 s |

The two paired comparisons improved the 10-lap total by 2.107 s and 2.144 s
respectively, or 2.125 s on average. All five tracked scored results have
`scored: true` and zero collisions. Unedited referee JSON files are in
`results/submitted/`; times above are rounded from those files.

The selected actor is `race_ws/src/team_driver/weights/residual_policy.npz`.
It was exported from SAC run `task5_racing_line_44_2500b`, seed 43, after
2,500 training steps. Training included one collision episode during
exploration, so the scored deterministic runs, rather than the training
episodes, are the basis for selecting it. The default `driver_params.yaml`
loads this actor. `config/baseline_44_params.yaml` preserves the classical
baseline at identical speed and safety settings.

The actor is a 24-64-64-2 NumPy MLP with bounded tanh outputs. In one short
scored-run sample, ROS received roughly 73-77 steering commands per wall-clock
second. This is a message-rate observation, not a proof of every individual
sensor deadline. The final selected run ended cleanly; after shutdown,
odometry showed 0 m/s and the simulator counters stayed at 12 laps and zero
collisions. The result JSON records a real-time factor of 0.86 for that run.

The 4.4 m/s setting is a **target**, not a physical speed cap. A separate
three-lap unscored trial observed 4.76 m/s peak speed with no collisions, so
the PI controller can briefly overshoot. The racing line is generated by
map-constrained smoothing and is not proven globally minimum-time. Further
gains should be judged on complete scored runs with collision penalties.

## Reproduce with the Windows simulator

Start the bridge, connect AutoDRIVE to `127.0.0.1:4567`, and select
Autonomous. Stop any manual driver. From the container with the worktree ROS
overlay sourced, use the official referee launch with `simulator:=false`:

```bash
ros2 launch roboracer_referee evaluate.launch.py \
  team:=DeepSpeedRobot_selected44 simulator:=false \
  driver_params:=/hackathon/.worktrees/task1-residual-rl-baseline/race_ws/src/team_driver/config/driver_params.yaml \
  output_dir:=/hackathon/.worktrees/task1-residual-rl-baseline/results
```

For the baseline, change `driver_params` to
`/hackathon/.worktrees/task1-residual-rl-baseline/race_ws/src/team_driver/config/baseline_44_params.yaml`.
In a fresh checkout mounted directly at `/hackathon`, omit the
`.worktrees/task1-residual-rl-baseline/` path component.
